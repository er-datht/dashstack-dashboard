# Accuracy

- Be specific — name actual function names, file paths, class names, screens, tables, columns/labels, measured values (px, colors) and API endpoints.
- Do not invent information that is not present in the diff, the code, or the details the user provided. If you cannot confirm something, leave it out and say so in the Notes.
- Use placeholders for anything the user must supply (URLs, IDs, video/screenshot links, e.g. `Video: <link>`, `campaign_id=1&delivery_set_id=1`).
- State what is **not** affected as explicitly as what **is** — it is what stops QA filing duplicates.
